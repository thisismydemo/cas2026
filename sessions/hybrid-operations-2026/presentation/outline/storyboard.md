# Hybrid Operations storyboard and claim map

Shared baseline for both sessions: the landing zone, the Arc workload resource groups, effective Azure Policy assignments, Defender for Cloud coverage, and Sentinel data and detection configuration. The SCVMM-hosted workloads and their Arc integration are part of this shared baseline. The demos use the configured environment, and each teaching slide explains the configuration a service needs rather than implying it is automatic. See the shared-environment contract.

Review date: 2026-09-30 (64 slides). This storyboard is the teaching authority for both Hybrid decks, which are built from it with detailed speaker notes and separate attendee explanations; preserve this sequence. The Arc sequence intentionally moves from definition → connecting one server → hands-on onboarding → the two ways to bring a VM into Arc (agent or SCVMM/VMware platform) → the multicloud connector → EC2 versus EKS → hands-on AWS onboarding → edge and legacy → all onboarding paths side by side → part two, meet the service and follow one order, then operate it in five sections each opened by a divider (Observe, Secure, Govern, Cost, Adopt); path separation is taught inside Observe, after telemetry.

Demo entries specify the teaching goal and the evidence each demo shows. The ten demo runbooks and the demo console follow this sequence. The deck presents the environment as deployed and configured; lab build status is tracked in lab/status/, not in this storyboard.
