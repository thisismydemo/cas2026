# Presentation

`outline/storyboard.md` defines the delivered 64-slide sequence. `dual-notes.json` contains separately authored speaker and attendee notes keyed by stable slide ID. `session-content.json` is the generated slide manifest; do not edit it by hand.

The build and export scripts are not part of this repository.

The event and personal slides (sponsors, About Me, contact, recommendations, Questions) use the approved event treatments; the About Me slide is a full-slide image. All technical diagrams, labels, connectors and presenter notes are native, editable PowerPoint shapes.

## Decks

| File | What it is |
|---|---|
| [`decks/hybrid-operations-2026-dark.pptx`](decks/hybrid-operations-2026-dark.pptx) | Speaker deck, 64 slides, with KEY POINTS, TALKING POINTS and PURPOSE notes |
| [`decks/hybrid-operations-2026-attendee-dark.pptx`](decks/hybrid-operations-2026-attendee-dark.pptx) | Attendee deck, the same 64 slides, with attendee explanations |

Speaker notes for every slide are KEY POINTS (short scannable bullets, also stored as `keyPoints`), then TALKING POINTS, then PURPOSE; attendee notes are self-contained explanations without presenter instructions. Both are stored in `dual-notes.json`; [`speaker-notes.md`](speaker-notes.md) and [`attendee-notes.md`](attendee-notes.md) are readable exports.
