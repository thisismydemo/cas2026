# Observability across clouds: reference deck storyboard

Review date: 2026-10-01. This storyboard is the authoritative contract for the reference deck built by `tools/Build-ObservabilityReferenceDeck.ps1` into this folder. It is independent of the CAS26 session deck and of the lab: no application, no demo, no event chrome. The only reused asset is the presenter's About slide.

**Audience and purpose:** a reference deck, read end to end once and then by chapter, for IT Pros, operators and the presenter's own team. It answers three questions: what observability is (everything it can include), how to plan for it across datacenters, Azure, AWS, GCP and edge, and how to implement and operate it with Azure as the management plane (Azure Arc) and Azure Monitor as the data plane, with OpenTelemetry and Prometheus as the open standards in and out. Chapters 3 to 7 go to engineering detail with commands and configuration.

**Facts:** from Microsoft Learn as read on 2026-10-01. Anything marked PREVIEW is subject to change.

**Theme:** Graphite and amber. Dark graphite background, amber lead accent, light text; chapter colours on the title-band tag and rule; diagram colours by estate: Azure blue, datacenter green, AWS amber-orange, GCP teal, Kubernetes purple.

**Row format.** Layout drives the build: `title`, `about`, `agenda`, `section`, `bullets`, `twocol`, `steps`, `table`, `code`, `grid`, `map`, `quote`, `diagram:<name>`. Content uses `;;` between items or lines, `~~` between columns, `::` between an item title and its body. No single `|` inside a cell.
