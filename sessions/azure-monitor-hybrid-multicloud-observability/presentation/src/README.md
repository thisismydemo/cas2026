# Source contract

The slide sources are [`../outline/storyboard.md`](../outline/storyboard.md) (one row per slide) and [`../dual-notes.json`](../dual-notes.json) (speaker notes, attendee notes and sources per slide ID). `../session-content.json` is generated and is not a source. The build and export scripts are not part of this repository. Demo commands and evidence boundaries live in [`../../demos/README.md`](../../demos/README.md).
