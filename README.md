# cas26

Materials for two independent 90-minute Cloud & AI Summit 2026 sessions.

| Session | Folder |
|---|---|
| Hybrid Operations in 2026: What IT Pros Need to Know | [sessions/hybrid-operations-2026/](sessions/hybrid-operations-2026/README.md) |
| Monitoring What Microsoft Doesn't Host: Azure Monitor for On-Prem and Multi-Cloud | [sessions/azure-monitor-hybrid-multicloud-observability/](sessions/azure-monitor-hybrid-multicloud-observability/README.md) |

Each session folder holds its presentation (presenter and attendee decks with notes), its demos (runbooks, console, scripts, queries) and its handouts. Both sessions use the same example application, IIC Hybrid Orders, running across Azure, AWS and an on-premises private cloud.

The sessions were delivered 30 September–2 October 2026. The Azure and AWS lab was torn down on 2 October 2026; commands and queries need your own environment.

## Repository organization

- `sessions/`: the two sessions, each with presentation, demos and handouts.
- [sessions/azure-monitor-hybrid-multicloud-observability/presentation/decks/observability-multicloud-reference/](sessions/azure-monitor-hybrid-multicloud-observability/presentation/decks/observability-multicloud-reference/storyboard.md): "Observability across clouds", an 87-slide reference deck.
